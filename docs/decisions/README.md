# Decision records

[`ARCHITECTURE.md`](../ARCHITECTURE.md) says how the app works now, and leaves a heading and a sentence where a record's whole text used to be, so a citation such as `§7, "The scratchpad"` still leads here.

A record describes the feature as it stands, so when a decision changes, amend its record in the same pull request.
