# CLA signatures

This branch exists only to hold contributor signatures, written here by
`.github/workflows/cla.yml` (`contributor-assistant/github-action`) as
`signatures/version1/cla.json`.

It has no code on it and is not merged into `main`. **It must not be
protected** — the action commits to it directly, and a protected branch fails
the check for everyone.

Each entry records a GitHub login and user id, the id and timestamp of the
comment the person signed with, and the pull request number. No email address,
and no part of anyone's contribution. All of it is already public about anyone
who has commented on a pull request here.

The agreement itself is [`CLA-individual.md`](https://github.com/skysa-org/skysa-notes/blob/main/CLA-individual.md)
on `main`, and [`CONTRIBUTING.md`](https://github.com/skysa-org/skysa-notes/blob/main/CONTRIBUTING.md#the-cla)
explains why it is a licence grant rather than an assignment.
