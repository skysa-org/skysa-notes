A secret can be given a label: a Label field over its words in the panel. The closed secret shows the label in place of "Secret", as do scratchpad cards, and search finds the note by it. The label is plain text on the secret's first line in the file (```` ```age Wi-Fi password ````), not encrypted, and the field says so. With no label, it still says "Secret". A version before this one opens a note with a labelled secret in raw mode, losing nothing.
