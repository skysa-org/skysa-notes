A note with no name now goes by its first words wherever one line has to say which note it is. On a phone, the note's dropdown in the bar at the top, and a scratchpad card's name there, show the start of the note's first line, cut to about 40 characters, instead of "Untitled". So does the notice after a note is deleted ("Deleted “Pick up the parcel”."). A note with no words is still "Untitled", and a scratchpad card with no words still shows no name in the bar.
