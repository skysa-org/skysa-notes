A password has a Site: the web address it fills in on, and the sites under it, encrypted with the username and password. It is a field after the label, which says when what is in it is not a web address. An item whose label is a web address is offered "Use github.com as the site" while its Site is empty. Opened, an item shows its Site's address with Open, in place of its label's.
