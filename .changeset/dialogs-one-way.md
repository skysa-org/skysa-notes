Every dialog now works the same way. Its buttons are one row at the end: Cancel (or Close) first, and the answer last, on the right. The first field has the focus when there is one, and the answer when there is not. Escape is Cancel everywhere, including the secret panel in a note, where it used to be Done; Mod+Enter is Done there. The storage panel's questions, and Delete on a file in a notebook's attached files, follow the same rules. Disconnect and "Discard for good" are now drawn as the warnings they are.
