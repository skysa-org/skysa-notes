A scratchpad for quick notes, for every source, the device's own notes included. Turn it on from the storage menu ("Show scratchpad"), and it sits above the notebooks: a "Take a note…" box, and the notes taken as cards, the pinned first. A card can be pinned and given a colour, which are kept in the note's file and so reach every device. It opens in a dialog, or the whole window on a phone, and "Move to notebook" makes it a full note, named first if it has no name. Scratch notes are ordinary notes in a hidden `.scratchpad` folder, synced as any note is, and search finds them while the scratchpad is shown.

Labels are spelled the American way where they were not: "Canceling…" while an import is called off, and "Connecting storage was canceled."
