A notebook whose notes are all in notebooks inside it now opens like any other notebook. On a phone, tapping one shows its notes to choose from. Before, it opened straight onto a note from one of the notebooks inside it, with no list. When it opens on a note by itself, it picks the first one its list shows, so pinned notebooks and pinned notes come first. Before, it started a new blank note instead. A note you had open last in that notebook is still the one it opens on.
